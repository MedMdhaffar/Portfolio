01 / COMPUTATIONAL IMAGING · GPU SYSTEMS

GPU-Accelerated Deep Image Prior for Image Denoising

Single-image reconstruction with Deep Image Prior, ADMM, TV/WTV regularization, and native PyTorch C++/CUDA operators—built to study both reconstruction behavior and GPU execution.

33.049 dBBest ADMM-DIP checkpoint
9.52×Periodic-gradient speedup
A100 80 GBProfiling platform
Research repositoryExplore the implementation↗

01 · Problem & motivation

Can the network architecture itself act as an image prior?

Deep Image Prior (DIP) fits an untrained convolutional network to a single noisy observation. Natural image structure is typically reconstructed before the network begins fitting noise, making optimization control and early stopping essential.

02 · Technical approach

DIP meets constrained optimization

I implemented vanilla DIP, then coupled it with ADMM—an optimization method that separates the neural reconstruction step from explicit TV/WTV regularization. Native CUDA operators cover periodic gradient, divergence, shrinkage, and dual updates, with autograd integration and a portable PyTorch fallback. I compared eager PyTorch, compiled PyTorch, and native CUDA paths, evaluated BM3D and other classical baselines, and added early stopping with best-checkpoint restoration to limit noise overfitting.

01 · Mission challenge

Keeping attitude-control telemetry dependable in orbit

CubeSat ADCS hardware operates under strict power, volume, thermal, and radiation constraints. A sensor anomaly can threaten pointing accuracy and mission continuity, while waiting for ground analysis adds delay. This project investigates onboard intelligence for faster fault detection and autonomous signal recovery.

02 · Dual-model strategy

Detect first, then reconstruct the signal

An Artificial Neural Network classifies incoming telemetry as normal or anomalous. When a fault is detected, one of nine channel-specific Random Forest regressors estimates a corrected value for the affected magnetometer or sun-sensor channel.

03 · End-to-end architecture

Telemetry → detection → correction → validated output

The STM32F429 sits inside the monitoring loop, consuming ADCS signals, running anomaly inference, and forwarding corrected data back toward the simulated bus interface.

01 · Problem

Biological knowledge lives in disconnected formats

Researchers move between article abstracts, sequence and protein repositories, and chemical representations. Different identifiers, data shapes, and search interfaces make it difficult to explore related evidence through one consistent workflow.

02 · Solution

A shared semantic layer across biological entities

Bio-Vector Orbit standardizes retrieval behind one interface. Users choose a discovery mode, submit text or a SMILES representation, and receive specialized results for literature, protein structures, or chemically similar molecules.

04 / FINAL PROJECT · MEDICAL AI

Robust Multi-Class Diabetic Retinopathy Detection

A hybrid deep-learning pipeline that grades diabetic retinopathy from retinal fundus images, adds model-trust safeguards, and packages predictions with privacy-oriented encryption and watermarking controls.

93.0%Validation accuracy
0.9566Quadratic Weighted Kappa
5 classesDR severity grading

01 · Clinical problem

Grading a progressive retinal disease

Diabetic retinopathy screening requires distinguishing subtle lesions across five ordered severity levels: No DR, Mild, Moderate, Severe, and Proliferative DR. The problem combines fine local texture recognition with global retinal context and substantial class imbalance.

02 · Design goal

Accuracy, ordinal agreement, and responsible outputs

The project combines a hybrid CNN–Transformer classifier with explainability, uncertainty estimation, and out-of-distribution checks. A second security phase protects patient metadata and predictions inside a DICOM-oriented workflow.

03 · End-to-end architecture

From fundus image to interpretable severity prediction

The 512 × 512 retinal input passes through image preparation and augmentation before a ConvNeXt–Swin hybrid combines local lesion features with global spatial relationships.

04 · Training pipeline

Built for retinal variation and class imbalance

The model has approximately 112.8 million trainable parameters. Training combines robust retinal preprocessing, strong augmentation, imbalance-aware loss, and ordinal evaluation.

PREPROCESSING
Preserve useful retinal detail

ROI crop, Ben Graham normalization, green-channel CLAHE, and resizing to 512 × 512.

AUGMENTATION
Increase visual diversity

Full-range rotation, horizontal and vertical flips, subtle zoom, MixUp α=0.4, and CutMix α=1.0.

OBJECTIVE
Handle difficult minority classes

Focal Loss γ=2 with label smoothing ε=0.1 and inverse-frequency class weights.

OPTIMIZATION
Stable end-to-end training

AdamW with a 1e−4 learning rate, 1e−5 weight decay, and cosine-annealing scheduling.
