# Mohamed Mdhaffar — Portfolio

A dependency-free personal portfolio built with semantic HTML, CSS, and a small amount of JavaScript.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

- Update portfolio copy and links in `index.html`.
- Change colors and layout in `styles.css` (design tokens are at the top).
- Keep `CV_mohamedMdhaffar.pdf` in the project root so the résumé link works.
